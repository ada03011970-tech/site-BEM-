# БЭМ — сайт Сергея и Марины (Fohow)

Сайт студии биоэнергетического массажа на оборудовании Fohow в Волгограде. Сергей и Марина — официальные представители Fohow.

Живая версия: https://bem.159-194-231-180.sslip.io

## Файлы

- `index.html` — главная страница (структура по образцу fohowkrd.ru, палитра "спокойная медицина" sage/white, официальный логотип Fohow, энергетическая анимация на первом экране)
- `privacy.html` — политика конфиденциальности
- `consent.html` — согласие на обработку персональных данных
- `og-image.jpg` — изображение для превью в соцсетях (Open Graph)
- `robots.txt`, `sitemap.xml` — файлы для поисковой индексации

## Важно перед публикацией

1. В `privacy.html` и `consent.html` остались незаполненные поля (отмечены жёлтым): полное ФИО Сергея, правовой статус (ИП / самозанятый / физлицо), ИНН. Без этого документы юридически неполные.
2. Фото Сергея и Марины в разделе "Мастера" — пока плейсхолдеры, не их реальные фото.
3. Отзывы клиентов в разделе "Что говорят клиенты" — тестовые заглушки, нужно заменить на реальные.

## Деплой

Сайт раздаётся через Caddy на VPS, конфиг `/etc/caddy/Caddyfile`, файлы лежат в `/var/www/bem/`. API формы записи (`/api/booking`) — отдельный сервис `bem-booking` (systemd), пересылает заявки в Telegram Сергею и Марине.
